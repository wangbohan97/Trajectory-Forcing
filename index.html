01Idea

Denoising trajectories are context for what comes next.

Trajectory Forcing turns intermediate denoising predictions into useful context for generating subsequent video chunks, across supervised training and self-rollout training.

Each column is one chunk’s denoising trajectory, from Gaussian noise at the top to its final output at the bottom.

In this conceptual view, the shaded history includes complete earlier trajectories and the current chunk’s earlier states. The arrow shows how this history conditions the current update. The current chunk’s initial noise is sampled without conditioning.

In practice, each update uses one selected clean-signal prediction from each retained preceding chunk. Selection details.

Selection · practical conditioning

Using trajectory context efficiently

Full-trajectory conditioning adds attention and memory cost. TraF uses one selected prediction per retained preceding chunk at each update.

Cache
Clean-signal predictions from preceding chunks, not noisy latents.
Context
One selected prediction from each retained preceding chunk at each denoising update.
Rule
On the finite denoising grid, select the available prediction nearest to the regularized target progress.
Selection rule continuous target & discrete steps

The continuous target scales the current step’s amplitude signal-to-noise ratio by γ.

Sγ(p) = γp1 + (γ − 1)p

p = 1 − σ is denoising progress, from noise (0) to clean signal (1); γ ≥ 1.

On the finite grid, TraF adds a regularization term to the target ratio and converts it to progress before selecting the nearest available prediction. See Appendix A of the paper.

γ = 1 is step-aligned. γ → ∞ approaches endpoint-only conditioning.
